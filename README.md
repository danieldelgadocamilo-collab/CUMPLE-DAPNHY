# Carta de cumpleaños para Dapnhy

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta.
3. Ve a Settings > Pages.
4. En 'Build and deployment', selecciona 'Deploy from a branch'.
5. Elige la rama `main` y la carpeta `/root`.
6. Guarda y espera unos minutos.
7. Comparte el enlace generado.

Puedes reemplazar `assets/musica.mp3` por la canción instrumental que prefieras y añadir imágenes en la carpeta assets.
